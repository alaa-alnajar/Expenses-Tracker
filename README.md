# Expense Tracker

<!-- Expense Tracker is a simple web application for managing personal expenses.

The application allows users to add, view, edit, delete, and filter expenses by category -->

## How to run

<!--  -->

**Backend**

1. Node.js
2. Express.js 

**Frontend**

1. HTML
2. CSS
3. JS
4. Bootstrap

## Features


- Add a new expense
- View all expenses
- Edit an expense
- Delete an expense
- Filter expenses by category
- Display total expenses
- Display number of expenses
- Display highest expense
- Form validation
- Loading spinner
- Success and error alerts
- Dark mode

#### How to Run

1. Open the `backend` folder in the terminal.
2. Install the required packages: m install


3. Create a `.env` file inside the `backend` folder and add the database information.
4. Make sure PostgreSQL is running and the database is created.
5. Start the backend server:

6. node server.js


7. Open `frontend/app.html` in the browser.
